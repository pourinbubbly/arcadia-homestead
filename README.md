# 🌾 Arcadia Homestead - Web3 5x5 Pixel Farm GameFi

![Arcadia Homestead Banner](screenshot_iso_fixed.png)

> **Arcadia Homestead** is a Stardew Valley-inspired 5x5 Grid Web3 Pixel Farming Simulation & GameFi Landing Page built on **Circle ARC Testnet** (Chain ID: `5042002`).

---

## 🌟 Key Features

- **🌾 5x5 Grid Farming Engine**: Plant, grow, water, and harvest 5 unique crops (Wheat, Carrot, Tomato, Strawberry, Pumpkin).
- **💰 Native ARC Testnet USDC Economy**: Harvest rare high-tier crops to accumulate native USDC in your Vault, and cash out directly into your Web3 wallet!
- **👑 Premium Pass Subscriptions**: Monthly (5 USDC) & Annual (45 USDC) passes unlocking 2x/3x growth speed, auto-sprinkler watering, and 0% marketplace fees.
- **🍃 Giant Pixel Leaf Sweep Transition**: Sticky scroll interactive showcase transition with authentic 384x384 pixel leaf wipe effects.
- **🎨 Animated 16x16 Pixel World Background**: Canvas-based 8-bit environment with drifting pixel clouds, swaying grass sparkles, and dynamic lighting.
- **🌐 5-Language Localization (i18n)**: Switch between **TR (Türkçe)**, **EN (English)**, **ES (Español)**, **ZH (中文)**, and **JA (日本語)** instantly.
- **⚡ Web3 Ethers.js v6 Integration**: Native MetaMask/Rabby wallet connect, transaction signatures, and testnet network validation.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla CSS3 (Custom Stardew Design Tokens), JavaScript (ES6+)
- **Graphics**: HTML5 2D Canvas (Pixel Art Engine)
- **Web3 Engine**: Ethers.js v6 (ARC Testnet - Chain ID `5042002` / `0x4cef52`)
- **Generator**: Python 3 (`build_5x5_farm.py`)

---

## 🚀 Quick Start & Local Run

Simply launch a local HTTP server:

```bash
python -m http.server 8080
```

Open your browser and navigate to:
👉 **`http://localhost:8080`**
